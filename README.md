# 🛒 বাজার দর | BazarDor

BazarDor is a price tracking web application that helps users explore daily market prices, compare product prices and monitor price changes in one place.

## 🚀 Technologies Used

- Next.js
- TypeScript
- Tailwind CSS
- daisyUI
- Better Auth
- React

## ✨ Key Features

1. **Daily Market Prices** — Browse product prices and units in Bangla.
2. **Price Change Tracking** — Identify rising and falling product prices.
3. **Category-Based Browsing** — Explore products by category.
4. **Product Details** — View individual product information.
5. **User Authentication & Profile** — Sign in and manage profile information.
